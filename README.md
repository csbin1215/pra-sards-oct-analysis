# SD-OCT retinal layer thickness in canine PRA vs SARDS — analysis code

Analysis code and de-identified data for:

> Cho S, Kim D, Kim T, Kim G, Seo J, Lee E, Kang S, Seo K. Comparison of Optical Coherence Tomography Findings between Progressive Retinal Atrophy and Sudden Acquired Retinal Degeneration Syndrome in dogs. *Journal of Veterinary Science* (submitted).

## Contents

| File | Description |
|---|---|
| `analysis.py` | Complete statistical analysis (Section 2.7 of the manuscript) |
| `data/retinal_thickness_eye_level.csv` | Manually measured SD-OCT layer thickness (μm) per eye; 16 dogs, 30 eyes |
| `data/age_by_dog.csv` | Age (years) per dog |
| `results/results.csv` | Output generated by `analysis.py` |
| `requirements.txt` | Python package versions used |

Thickness columns: `TRT` total retinal thickness, `IRT` inner retinal thickness, `ORT` outer retinal thickness,
`ONL` outer nuclear layer, `PR_ISOS` photoreceptor inner/outer segment layer. Dog IDs (P1–P5, S1–S11) match
Tables 1 and 2 of the manuscript and contain no owner or hospital identifiers.

## Methods implemented

1. Age comparison between groups — Mann-Whitney U test (two-sided).
2. Exact permutation test of the difference in group means (SARDS − PRA), permuting group labels at the
   dog level across all C(16,5) = 4,368 possible splits, so that the two eyes of a dog always stay together.
3. Benjamini-Hochberg false discovery rate adjustment across the five parameters.
4. Dog-level (cluster) bootstrap 95% confidence intervals, 10,000 resamples, random seed 12345.

## How to run

Requires Python 3.12.

```bash
pip install -r requirements.txt
python analysis.py
```

Results are printed to the screen and saved to `results/results.csv`. The permutation test is exact, so its
p-values are identical on every run; bootstrap intervals are reproducible because the random seed is fixed.
